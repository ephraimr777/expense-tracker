# 💰 Expense Tracker

A modern Expense Tracker web application built using React, Firebase, and Tailwind CSS. It helps users manage their income, expenses, budgets, and financial insights through an intuitive dashboard.

## 🚀 Live Demo

https://expense-tracker-eight-sigma-29.vercel.app

## 📂 GitHub Repository

https://github.com/ephraimr777/expense-tracker

---

## ✨ Features

- 🔐 Firebase Authentication
- 📊 Dashboard Analytics
- 💵 Income & Expense Tracking
- 💰 Budget Management
- 📈 Interactive Charts
- 🔍 Search Transactions
- 📅 Date Filtering
- 📄 Export to CSV
- 📑 Export to PDF
- 🌙 Dark Mode
- 🔔 Toast Notifications
- 🗑 Delete Confirmation Modal
- 📱 Fully Responsive Design

---

## 🛠 Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- React Router
- Recharts
- React Toastify

### Backend / Database

- Firebase Authentication
- Cloud Firestore

### Deployment

- Vercel

## Installation

```bash
git clone https://github.com/ephraimr777/expense-tracker.git

cd expense-tracker

npm install

npm run dev
```
